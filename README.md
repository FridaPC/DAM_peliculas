# Catálogo de películas

Aplicación móvil desarrollada con Flutter que permite explorar un catálogo de películas, ver detalles de cada título y administrar el contenido.

## Cómo ejecutar la aplicación

### Requisitos previos
- Flutter SDK instalado
- Android Studio o VS Code
- Emulador Android/iOS o dispositivo físico

### Pasos para ejecutar
1. Clona este repositorio:
   ```
   git clone https://github.com/epickatif/ldsw-catalogo-peliculas-flutter.git
   ```

2. Navega al directorio del proyecto:
   ```
   cd ldsw-catalogo-peliculas-flutter
   ```

3. Instala las dependencias:
   ```
   flutter pub get
   ```

4. Ejecuta la aplicación:
   ```
   flutter run
   ```

## Cómo usar la aplicación

### Navegación básica
1. **Pantalla de inicio**: Al abrir la aplicación, verás la pantalla de bienvenida con opciones para iniciar sesión o registrarte.

2. **Registro/Inicio de sesión**: Puedes crear una cuenta nueva o iniciar sesión con una cuenta existente.

3. **Catálogo de películas**: Después de iniciar sesión, accederás al catálogo donde puedes ver todas las películas disponibles.

4. **Búsqueda**: Usa la barra de búsqueda para encontrar películas por título, director o género.

5. **Detalles de película**: Toca cualquier película para ver información detallada como título, año, director, género y sinopsis.

### Funciones de administración
Para acceder a las funciones de administración (agregar, editar o eliminar películas), inicia sesión con una cuenta de administrador.
